# Frontend UI Skill

Use this skill when creating or modifying React UI.

Rules:
- Use React + TypeScript.
- Use Tailwind CSS.
- Prefer reusable components.
- Keep styling consistent with `docs/UI_DESIGN_SYSTEM.md`.
- Preserve the light theme.
- Do not introduce dark-theme defaults unless requested.
- Ensure responsive behavior.
- Use accessible buttons, labels, and focus states.
- Avoid hardcoded repeated layouts.
